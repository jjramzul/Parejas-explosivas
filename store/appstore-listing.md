## Notas para el revisor (App Review Information)
```
No account or login is required. All modes can be tested without signing in.

Online mode: tap "Online" and then "Create room" to get a 6-character room code. A second device can join with "Join with code" (or by scanning the QR). The game needs 2+ players in the room to start. If you can't test with two devices, the modes "2 players" and "Machine" cover all game rules and powers without internet.

Player names are free text but are filtered for offensive words, and there is no free-text chat (only preset reactions).
```
